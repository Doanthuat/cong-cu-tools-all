Kết quả kiểm tra link ảnh

Lọc nhanh, sắp xếp, thao tác từng dòng hoặc thao tác hàng loạt.

Empty state: Chưa có dữ liệu. Hãy nhập URL và bấm Bắt đầu kiểm tra.
Loading state: Đang kiểm tra link ảnh, vui lòng chờ...
Error state: File nhập sai định dạng. Vui lòng dùng file .txt hoặc .csv.
Success state: Hoàn tất kiểm tra. Bạn có thể lọc hoặc xuất dữ liệu.
No result state: Bộ lọc hiện tại không có dữ liệu phù hợp.
